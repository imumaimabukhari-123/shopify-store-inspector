Install it in 1 minute

It isn't on the Chrome Web Store yet, so it's installed from the download. The guide walks you through it step by step.

1

Download

Click Download the extension and unzip the file.

2

Open extensions

Go to chrome://extensions in Chrome.

3

Developer mode

Turn on Developer mode (top right), click Load unpacked.

4

Choose the folder

Select the unzipped folder. Pin the 🔎 icon and click it on any store.
