How to use the Shopify Store Inspector

Install the extension in a minute, then inspect any store with one click. No coding needed.

1. Installing the extension

Works in Google Chrome, Microsoft Edge and Brave on a computer.

1

Download and unzip

On the home page, click Download the extension. Open your Downloads folder, right-click shopify-store-inspector.zip and choose Extract All…, then Extract.

2

Open the extensions page

In Chrome's address bar, type chrome://extensions and press Enter. (In Edge: edge://extensions.)

3

Turn on Developer mode

Switch on Developer mode in the top-right corner. New buttons appear.

4

Load the folder

Click Load unpacked and select the unzipped shopify-store-inspector folder (the one that contains manifest.json).

5

Pin it

Click the puzzle-piece icon 🧩 next to the address bar, then the pin 📌 next to Shopify Store Inspector. The purple 🔎 icon now stays in your toolbar.

💡 Keep the unzipped folder. If you delete it, Chrome removes the extension.

2. Inspecting a store

  1. Open any online store in a tab, for example kith.com.
  2. Click the purple 🔎 icon. The report appears in a few seconds.
  3. To check another store without leaving the page, type its address in the box at the top of the popup and click Go.
  4. Click Get AI tips for 5 suggestions, or Copy report to paste a summary into an email or proposal.
💡 It inspects the page you're on. Open a product or collection page to check that page's SEO.

3. Reading the report

SectionWhat it tells you
Shopify store ✓Whether the site runs on Shopify, and the evidence (headers, theme code, Shopify CDN files).
Store at a glanceNumber of products and collections, price range, average price, % on sale, % sold out, currency and shipping countries.
ThemeThe theme's name and version, and whether it's from the Shopify Theme Store or custom-made.
Apps & toolsApps spotted in the page's code, grouped by type (email, reviews, payments, support, analytics…).
CatalogTop product types, newest products, and products missing images or descriptions.
SEO check9 checks of the current page with a score out of 100. ✓ = good, ! = could be better, ✕ = needs fixing.
AI tipsThe 5 changes that would help most, each marked high, medium or low impact.
⚠️ Prices and sales are based on the first 250 products. Apps are only detected if they load on the page, so some apps (for example, back-office apps) can't be seen.

4. Using it without installing

On a phone, or don't want to install anything? Use Inspect a store on this website. Type a store's address and you get the same report.

5. Fixing problems

You see…What to do
"Open a store first"You clicked the icon on a Chrome page (like a new tab). Open a website first, or type an address in the box.
"Couldn't open that website"Check the address. Some sites block automatic visits; try another page of the store.
"Not a Shopify store"The site runs on something else (WooCommerce, Wix…). The SEO check still works.
🔒 "password-protected"The store isn't open to the public yet, so only limited data is visible.
"Couldn't reach the inspector"Check your internet connection and try again.
"You've reached the hourly limit"This free tool allows about 40 inspections and 15 AI tips per hour. Try again later.
"Manifest file is missing" when loadingYou selected the wrong folder. Select the folder that directly contains manifest.json.

6. FAQ

Is it free?

Yes. The AI tips run on Google Gemini's free tier, with fair-use limits per hour.

Is it safe? What does it read?

It only reads the address of the tab you click it on, and only when you click it. See the privacy page for details.

Why isn't it on the Chrome Web Store?

It's a portfolio project, so it's installed from the download for now. It uses only one permission (activeTab).

Can you build a custom extension for me?

Yes. I build Chrome extensions and Shopify tools. See the Developer section.
